# Spotify and YouTube Analytics Dashboard

## Project Overview

This dashboard presents an overview of music performance across Spotify
and YouTube. It brings key metrics and visualizations together to help
explore streaming activity, audience engagement, artist performance,
track catalogue composition, and trends shown in the dataset.

## Dashboard Highlights

-   **Total Spotify Streams:** 3T
-   **Total Likes:** 13bn
-   **Total YouTube Views:** 2T
-   **Total Tracks:** 21K
-   **Top Artists by Spotify Streams:** Compares the leading artists
    displayed in the dashboard.
-   **Top Tracks by YouTube Views:** Highlights tracks with the highest
    view counts in the chart.
-   **Album Type Distribution:** Shows the share of album, single, and
    compilation tracks.
-   **Track Licensing Status:** Summarizes the licensing categories
    represented in the dataset.
-   **Monthly Trends:** Displays the sales/views and profit trends
    included in the dashboard.

## Key Insights

-   The dashboard reports approximately **3T Spotify streams**, **2T
    YouTube views**, **13bn likes**, and **21K tracks**.
-   **Post Malone** leads the displayed ranking of artists by Spotify
    streams.
-   **Despacito** leads the displayed ranking of tracks by YouTube
    views.
-   Albums make up the largest share of tracks shown, at approximately
    **72.04%**.
-   The displayed profit trend generally declines across the categories
    shown.

## Tools and Concepts

-   **Power BI** for dashboard visualization and reporting
-   KPI cards, bar charts, doughnut/pie charts, and trend charts
-   Descriptive analysis and comparison of music performance metrics

## Purpose

The project demonstrates how descriptive analytics can turn
music-platform data into an easy-to-read dashboard. It helps users
compare artist reach, track popularity, catalogue composition, and the
trends represented in the data.

## Notes

The figures and insights in this README are based on the supplied
dashboard and should be interpreted in the context of its dataset. The
trend visuals use the categories shown in the dashboard; they should not
be treated as verified calendar-month results unless the underlying data
confirms that interpretation.
